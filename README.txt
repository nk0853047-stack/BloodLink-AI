BLOODLINK AI - VS CODE SETUP
=============================

1. Extract this folder.
2. Open the BloodLink-AI folder in VS Code.
3. Open index.html.
4. Run with VS Code Live Server, or double-click index.html.
5. Login using any valid email and any password.
   Example:
   Email: admin@bloodlink.ai
   Password: admin123

Project:
- index.html = login
- pages/dashboard.html = main dashboard
- pages/predictions.html = prediction simulator
- pages/inventory.html = blood inventory
- pages/donors.html = donor matching
- pages/hospitals.html = hospital network
- pages/alerts.html = emergency alerts
- style.css = complete UI styling
- script.js = interactions and demo prediction logic

NOTE:
This is a hackathon frontend prototype. Data and prediction calculations are simulated.
No real patient/donor medical data is included.
